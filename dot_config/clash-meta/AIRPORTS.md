## 测直连的方法论

- 先验环境再信数据：mihomo TUN 开启时 DNS 返回 198.18.0.0/15 fake-ip，curl 结果全部经代理，不是直连。测直连前确认无 proxy 环境变量、无 tun 接口（`ip -br link`、`env | grep -i proxy`）。
- DNS 判断污染：直连结果与境外 DoH/权威解析对照，解析到保留段或明显无关网段（如 Facebook 段）即为污染。
- 403 与 000 的区分：TLS 握手完整后收 Cloudflare 403（“Just a moment”盾页）说明站点活着，浏览器可过盾；连接超时或秒断才是被墙。curl 过不了 JS 挑战，属正常。
- 本机无 dig/nslookup，用 `resolvectl query` 或 DoH（`https://dns.alidns.com/resolve?name=...`）。
