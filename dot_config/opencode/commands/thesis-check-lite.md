# 论文总检

## 第一步：检查

派多个子 Agent 同时检查论文：
1. 不启用技能，验证是否符合 `AGENTS.md` 要求。
2. 启用 `cnki-aigc-rewrite` 检查 AI 痕迹。
3. 启用 `thesis-writer` 并读取其中的 AI 痕迹消除部分，分析是否有可优化点。
4. 启用 `thesis-writer` 读取参考文献，审查学术严谨性等相关项。

### 注

检查 agent 只分析问题，禁止修改内容。

## 第二步：修改

对全部问题（无论高/中/低危）判断能否修复，然后派修复子 Agent 修复。
如果可以修复，须确保内容准确诚实等基本要求。
禁止同时派遣多个子 Agent 修复。推荐多次派遣子 Agent ，每个子 Agent 修复一类问题。

## 第三步：复查

回到第一步，用相同提示词，重新启动各子 Agent。
注：
- 不要带上轮修改。
- 不要复用旧会话。

如此循环，直到问题全部解决。
最终报告发现的问题，包括已解决/未解决的部分，分析后续可做的事。
