# 论文总检

## 第一步：检查

派多个子 Agent 同时检查论文：
1. 以 `AGENTS.md` 为基准验证，不依赖额外 skill。
2. 启用 `cnki-aigc-rewrite` 检查 AI 痕迹。
3. 启用 `thesis-writer` 并读取其中的 AI 痕迹消除部分，分析可优化点。
4. 启用 `thesis-writer` 读取参考文献，审查学术严谨性。
5. 启用 `humanizing-text` 检查 AI 痕迹，分析可改进点并确保事实准确。
6. 事实核查：每个子 Agent 各检查一个方面。

### 注

检查 agent 只分析问题，禁止修改内容。

## 第二步：修改

对全部问题（无论高/中/低危）判断能否修复，然后派修复子 Agent 修复。
如果可以修复，须确保内容准确诚实等基本要求。
每次只派一个子 Agent 修复一类问题——多类问题分多次派遣，逐一修复。

## 第三步：复查

回到第一步，用相同提示词，以全新会话重新启动各子 Agent。

如此循环，直到问题全部解决。
最终报告发现的问题，包括已解决/未解决的部分，分析后续可做的事。
