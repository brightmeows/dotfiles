# 并行更新 AGENTS.md 和代码注释

## 第一步：检查

以项目内每个 `AGENTS.md` 文件为单位，启动检查子Agent。
- 检查目标：`AGENTS.md` 内容、代码注释。
- 唯一事实来源：代码实际实现。

### 注意

检查 agent 仅用于分析问题，禁止修改内容。
禁止携带上一轮修复信息，禁止复用已有会话。

## 第二步：修复

如果第一步发现问题，派遣对应的修复子Agent进行修复。
禁止修改代码实际实现。

## 第三步：回到第一步

循环，直至所有内容完全对齐。

## 循环完成后

报告所有修复内容。
