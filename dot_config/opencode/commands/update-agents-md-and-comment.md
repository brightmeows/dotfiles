# 并行更新 AGENTS.md 和 代码注释

循环以下两个步骤，直至所有内容完全对齐。

## 第一步：检查

以当前项目内的每个 `AGENTS.md` 文件为单位，启动检查子Agent：
- 检查目标：`AGENTS.md` 内容、代码注释。
- 唯一事实来源：代码实际实现。

### 注意事项

派遣检查子Agent时，禁止携带上一轮修复信息，禁止复用已有会话。

## 第二步：修复

如果第一步发现问题：
- 派遣对应的修复子Agent进行修复。
- 禁止修改代码实际实现。

## 循环完成后

报告所有修复内容。
