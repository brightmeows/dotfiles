# Code Review 循环

## 第一步：审查

启动 code reviewer 子 agent，检查当前分支与 main 分支的 diff。
查找实现问题和可优化点。

### 注

审查 agent 只分析问题，禁止修改内容。

## 第二步：修改

报告发现的全部问题，修复其中可修复的部分。
运行项目检查并修复，然后提交，完成一轮。

## 第三步：复查

回到第一步，开始下一轮循环。
再次派遣 code reviewer 子 agent 时，不要携带上一轮修复内容，不要复用上一轮的会话。

如此循环，直到无问题。
