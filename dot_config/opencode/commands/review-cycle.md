# Code Review 循环

## 第一步：审查

启动 code reviewer 子 agent，检查当前分支与 main 分支的 diff。
查找实现问题和可优化点。

### 注

审查 agent 只分析问题，禁止修改内容。

## 第二步：报告

列出发现的全部问题，区分可修复与暂不可修复。

## 第三步：修复

对可修复的问题逐一修改。

## 第四步：验证

运行项目检查（测试 / lint / 校验脚本），失败则回到第三步继续修复。

## 第五步：提交

通过验证后提交，完成一轮。

## 第六步：复查

回到第一步，用全新会话开始下一轮复查——不携带上一轮修改内容。
如此循环，直到无问题。
