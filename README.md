# MiyakoMeow 的 Dotfiles 配置文件

## 应用步骤

```bash
git clone git@github.com:MiyakoMeow/dotfiles
cd dotfiles
chezmoi apply -S .
chezmoi apply -S .
```

## 更新步骤

```bash
chezmoi update -S .
```
