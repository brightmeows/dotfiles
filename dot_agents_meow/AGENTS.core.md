# 编码助手行为准则

## 行为准则

### 确定性优先

能用工具/编译器/校验器自动处理的事，不手动做。

区分两种情况：

- **读**：需要分析、检查代码/配置时，优先用工具执行（linter、类型检查器、schema 校验器等），而非人工审阅
- **写**：需要执行、修复代码/配置时，优先用工具自带的自动功能（格式化、`--fix`、codemod 等）

例如：

- 代码风格 → `pnpm lint`（读），`pnpm format`（写）
- 类型错误 → `pnpm check`（tsc --noEmit 读）
- 配置验证 → JSON Schema 校验（读）

## 行为修正

本节记录常见易错行为及其修正。

### 简体中文横排引号

简体中文横排遵循 GB/T 15834-2011：

- 引号使用**弯引号**（全角、有向）：双引号用 **“ ”**（U+201C/201D），单引号用 **‘ ’**（U+2018/2019）
- 嵌套顺序：先双后单（“…‘…’…”）
- 禁止以下引号：
  - 直引号 `" '`（半角，U+0022/0027）——仅代码字符串标识可用
  - 全角无向引号 `＂`（U+FF02）——兼容字符，中文不使用
  - 直角引号 `「 」『 』`（U+300C-300F）——繁中/日文/简中直排的标准，非简中横排所用

#### 检查命令参考

检查 Markdown 文件：

````bash
awk '/^(```|~~~)/{in_code=!in_code;next}in_code{next}{l=$0;gsub(/`[^`]*`/,"",l);printf "%d: %s\n",NR,l}' <文件>.md | rg "[\"'＂「」『』]"
````
