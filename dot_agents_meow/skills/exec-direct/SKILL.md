# 当前会话执行

## 概览

加载蓝图文档，审查后按任务清单逐项在当前会话中执行，设置检查点汇报进展。

**开始前宣布：** “正在使用 exec-direct 执行此计划。”

## 流程

### 步骤 1：加载并审查计划

1. 读取蓝图文档
2. 审查计划——识别潜在问题或疑问
3. 如有问题：先向用户提出
4. 如无问题：创建 Todowrite 开始执行

### 步骤 2：执行任务

对每个任务：
1. 标记为 `in_progress`
2. 严格按每步描述执行
3. 按说明运行验证
4. 标记为 `completed`，设置检查点

### 步骤 3：完成

所有任务完成后：
- 汇总完成情况
- 运行完整测试套件确保无回归
- 分发 `code-reviewer` 全面审查整个实现（如全量测试已运行通过，构造 prompt 时注明不需重复跑测试命令）
- 向用户报告结果

## 异常处理

### 停止执行并求助
遇到以下情况**立即停止**，问清楚再继续：
- 阻塞：依赖缺失、测试失败、指令不清晰
- 计划缺陷：存在妨碍启动的严重问题
- 不理解：某条指令语义不清
- 验证反复失败

**不要猜测。不要强行通过阻塞。**

### 返回步骤 1 审查
以下情况回到步骤 1，重新审查计划：
- 用户根据反馈更新了计划
- 需要重新思考基本方案或架构

## 快速参考

| 阶段 | 动作 |
|------|------|
| 加载审查 | 读计划 → 批判性审查 → 有问题先问 → 创建 Todowrite |
| 逐任务执行 | 标记 in_progress → 按步执行 → 验证 → 标记 completed |
| 完成收尾 | 汇总 → 全量测试 → 分发 code-reviewer → 报告 |

## 常见错误

| 错误 | 修复 |
|------|------|
| 跳过计划审查直接执行 | 先质疑计划，识别潜在问题后再开始 |
| 阻塞时猜测继续 | 停——直接问清楚，不猜测 |
| 跳过验证步骤 | 每步按说明运行验证，不省略 |
| 在 main/master 分支实施 | 先用 git worktree 创建隔离工作区 |
