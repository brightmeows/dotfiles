# 当前会话执行

## 概览

加载蓝图文档，审查后按任务清单逐项在当前会话中执行，设置检查点汇报进展。

**开始前宣布：** “正在使用 inline-execution 执行此计划。”

## 流程

### 步骤 1：加载并审查计划

1. 读取蓝图文档
2. 审查计划——识别潜在问题或疑问
3. 如有问题：先向用户提出
4. 如无问题：创建 Todowrite 开始执行

### 步骤 2：执行任务

对每个任务：
1. 标记为 `in_progress`
2. 严格按每步描述执行
3. 按说明运行验证
4. 标记为 `completed`，设置检查点

### 步骤 3：完成

所有任务完成后：
- 汇总完成情况
- 运行完整测试套件确保无回归
- 向用户报告结果

## 何时停止求助

**立即停止执行：**
- 遇到阻塞（依赖缺失、测试失败、指令不清晰）
- 计划存在妨碍启动的严重缺陷
- 不理解某条指令
- 验证反复失败

**直接问清楚，不要猜测。**

## 何时返回审查

**返回步骤 1，当：**
- 用户根据反馈更新了计划
- 需要重新思考基本方案

**不要强行通过阻塞** —— 停下来问。

## 要点

- 先批判性审查计划
- 严格按计划步骤执行
- 不跳过验证
- 阻塞时停下，不猜测
- 切勿在 main/master 分支上直接开始实施
