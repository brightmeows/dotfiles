# 技能设计中的说服原则

## 概述

LLM 与人类一样响应相同的说服原则。理解这一心理有助于你设计更有效的技能——目的不是操控，而是确保关键实践在压力下仍被遵守。

**研究基础：** Meincke 等人（2025）在 N=28,000 个 AI 对话中测试了 7 项说服原则。说服技术使遵从率提升至两倍以上（33% → 72%，p < .001）。

## 七项原则

### 1. 权威
**定义：** 对专业、资质或官方来源的服从。

**技能中如何生效：**
- 命令式语言：“YOU MUST”、“Never”、“Always”
- 非协商框架：“No exceptions”
- 消除决策疲劳与合理化借口

**使用时机：**
- 纪律执行型技能（TDD、验证要求）
- 安全关键实践
- 既定最佳实践

**示例：**
```markdown
✅ 先写代码后写测试？删除它。重新开始。无例外。
❌ 条件允许时可考虑先写测试。
```

### 2. 承诺
**定义：** 与先前行动、声明或公开表态保持一致。

**技能中如何生效：**
- 要求公告：“告知正在使用技能”
- 强制明确选择：“选 A、B 或 C”
- 使用跟踪：TodoWrite 标记清单

**使用时机：**
- 确保技能被实际遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ 找到技能时，你 MUST 声明：“我正在使用 [技能名称]”
❌ 可考虑告知伙伴你正在使用哪个技能。
```

### 3. 稀缺性
**定义：** 时间限制或有限可用性带来的紧迫感。

**技能中如何生效：**
- 时间绑定要求：“继续前必须先做”
- 顺序依赖：“完成 X 后立即”
- 防止拖延

**使用时机：**
- 即时验证需求
- 时间敏感型工作流
- 防止“我稍后再做”

**示例：**
```markdown
✅ 完成任务后，IMMEDIATELY 请求代码审查，之后再继续。
❌ 你可以在方便时审查代码。
```

### 4. 社会认同
**定义：** 从众于他人所为或被视为正常的行为。

**技能中如何生效：**
- 普遍模式：“每一次”、“总是”
- 失败模式：“有 X 无 Y = 失败”
- 建立规范

**使用时机：**
- 记录普遍实践
- 警告常见失败
- 强化标准

**示例：**
```markdown
✅ 清单无 TodoWrite 跟踪 = 步骤被跳过。每一次。
❌ 有些人觉得 TodoWrite 对清单有用。
```

### 5. 统一性
**定义：** 共同身份——“我们感”、群体归属。

**技能中如何生效：**
- 协作语言：“我们的代码库”、“我们是同事”
- 共同目标：“我们都追求质量”

**使用时机：**
- 协作工作流
- 建立团队文化
- 非等级制实践

**示例：**
```markdown
✅ 我们是共事的同事。我需要你诚实的技术判断。
❌ 如果我错了，你或许应该告诉我。
```

### 6. 互惠
**定义：** 回报已收好处的义务。

**如何生效：**
- 谨慎使用——可能让人感到被操控
- 技能中很少需要

**何时避免：**
- 几乎总是避免（其他原则更有效）

### 7. 好感
**定义：** 倾向于与喜欢的人合作。

**如何生效：**
- **不要用于遵从性**
- 与诚实反馈文化冲突
- 催生谄媚行为

**何时避免：**
- 纪律执行的场景始终避免

## 按技能类型的原则组合

| 技能类型 | 使用 | 避免 |
|---------|------|------|
| 纪律执行型 | 权威 + 承诺 + 社会认同 | 好感、互惠 |
| 指导/技巧型 | 适度权威 + 统一性 | 过度权威 |
| 协作型 | 统一性 + 承诺 | 权威、好感 |
| 参考型 | 仅清晰性 | 所有说服原则 |

## 为何有效：背后的心理

**明确红线减少合理化：**
- “YOU MUST” 消除决策疲劳
- 绝对化语言消灭“这算例外吗？”的疑问
- 明确的抗合理化对位关闭具体漏洞

**执行意图创造自动化行为：**
- 清晰触发器 + 必需行动 = 自动执行
- “当 X 发生时做 Y” 优于“通常做 Y”
- 降低遵从的认知负担

**LLM 是拟人的：**
- 训练数据中包含这些模式的人类文本
- 权威语言在训练数据中先于遵从出现
- 承诺序列（声明 → 行动）被频繁建模
- 社会认同模式（人人都做 X）建立规范

## 伦理使用

**正当：**
- 确保关键实践被遵循
- 创建有效的文档
- 预防可预见的失败

**不正当：**
- 为个人利益操控
- 制造虚假紧迫感
- 基于内疚的遵从

**判断标准：** 如果用户完全理解，这项技术是否服务于其真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 说服七原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 在 N=28,000 次 LLM 对话中测试了 7 项原则
- 说服技术使遵从率从 33% 提升至 72%
- 权威、承诺、稀缺性效果最强
- 验证了 LLM 行为的拟人模型

## 快速参考

设计技能时自问：

1. **这是什么类型？**（纪律 vs 指导 vs 参考）
2. **我想改变什么行为？**
3. **适用哪些原则？**（纪律型通常用权威 + 承诺）
4. **组合过多了吗？**（不要七项全用）
5. **这合乎伦理吗？**（是否服务于用户的真实利益？）
