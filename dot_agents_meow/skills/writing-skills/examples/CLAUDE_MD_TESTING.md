## 测试协议

对每个变体：

1. **先跑 NULL 基线**（无技能文档）
   - 记录 agent 选择了哪个选项
   - 精确捕获合理化借口

2. **用同一场景跑变体**
   - agent 是否检查技能？
   - 找到技能后是否使用？
   - 若违反则捕获合理化借口

3. **压力测试**——加入时间/沉没成本/权威压力
   - agent 在压力下是否仍检查？
   - 记录遵从性何时崩溃

4. **元测试**——问 agent 如何改进文档
   - “你有文档但没检查。为什么？”
   - “文档怎样才能更清晰？”

## 成功标准

**变体成功条件：**
- agent 主动检查技能，无需提示
- agent 在行动前完整阅读技能
- agent 在压力下仍遵循技能指导
- agent 无法用合理化借口规避遵从

**变体失败条件：**
- agent 即使无压力也跳过检查
- agent 不阅读，直接“领会精神”就动手
- agent 在压力下用合理化借口规避
- agent 将技能视为参考而非要求

## 预期结果

**NULL：** agent 选择最快路径，不知有技能

**变体 A：** 无压力时可能检查，有压力时跳过

**变体 B：** agent 有时检查，容易合理化规避

**变体 C：** 遵从性强，但可能感觉过于僵硬

**变体 D：** 平衡，但较长——agent 会内化吗？
